Modelo de Negocio — CazaPhish (SaaS B2B / B2G)

1. Propuesta de Valor

  • IA Explicable (XAI): Diagnóstico en semáforo (ALTO, MEDIO, BAJO) con motivos exactos y recomendación preventiva.
  • Soberanía y Privacidad: Enmascaramiento automático de PII en el Edge de Cloudflare sin hardware local.
  • Human-in-the-loop: La IA alerta y educa; el funcionario conserva la decisión final.

2. Segmentos de Clientes

  • Sector Público (B2G): Ministerios, entes recaudadores, alcaldías y universidades.
  • Sector Corporativo (B2B): Empresas, banca, seguros y comercios.
  • Integradores y MSP: Plataformas que conectan bots de WhatsApp, Telegram o correo.

3. Fuentes de Ingresos

  • Capa Pública Gratuita: Acceso web base para funcionarios y ciudadanía.
  • Plan Pyme / Pro: Suscripción mensual con API Keys para bots y alertas Webhook.
  • Plan Institucional / Enterprise: Licencia anual B2B/B2G con alto volumen, auditoría extendida y soporte SLA.

4. Canales y Relación

  • Portal Web Autoservicio: Registro y gestión directa desde la consola SaaS.
  • API REST & Webhooks: Integración en flujos de mensajería y pasarelas de correo.
  • Alianzas Estratégicas: Pilotos institucionales impulsados junto a UNETI y CAVECOM-E.

5. Recursos y Socios Clave

  • Stack Edge Serverless: Cloudflare Workers, Workers AI (Llama 3.1) y SQLite D1.
  • Motor Propietario: Reglas de anonimización de datos y prompts especializados.
  • Equipo ALPHA: Talento multidisciplinario respaldado por UNETI y CAVECOM-E.

6. Estructura de Costos

  • Cero Inversión en Servidores: Sin compra ni mantenimiento de GPUs físicas.
  • Pago por Uso Real: Escalabilidad automática proporcional al consumo de clientes activos.
  • Márgenes SaaS Altos: Costos operativos mínimos en la red global de Cloudflare.
